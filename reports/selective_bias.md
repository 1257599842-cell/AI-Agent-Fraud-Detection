# 选择性偏差演示（防守点⑤）—— 选择性标签 → 衰减 → 抽检救回

机制：只有被拦复核的拿真标签；放行的默认当 legit 喂回训练 → 漏掉的欺诈被标成好人 → 模型越练越窄。
bootstrap day<60 → 批次 [60,90)[90,120)[120,150) → 固定真标签 test day>=150（欺诈 3,213）。
拦截 top 2%；recovery 额外随机抽检 2% 放行样本。

## 每轮 test ROC-AUC

| 轮 | naive ROC | naive 末轮误标欺诈 | recovery ROC |
|----|-----------|-------------------|--------------|
| 0 | 0.8721 | 0 | 0.8721 |
| 1 | 0.8646 | 2123 | 0.8709 |
| 2 | 0.8579 | 2417 | 0.8666 |
| 3 | 0.8478 | 1774 | 0.8657 |

## 结论（按实际数字）
- naive 衰减：ROC 0.8721 → 0.8478（Δ -0.0243）——放行欺诈被当好人喂回，模型逐轮变窄。
- recovery：ROC 0.8721 → 0.8657；末轮相对 naive 救回 +0.0178。
- 机制量化：naive 末轮把约 (见表) 笔真欺诈误标成 legit；随机抽检用少量无偏样本打破闭环。
- 接 ⑩：这就是回流偏差的来源，探索预算（随机放行抽检）是无偏锚定；delta 记 naive→recovery。
